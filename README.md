# artefatos-manual-selenium-ide

Etapa 1:
 - Entrada: Plano de testes / requisitos atualizados.
 - Saída: Lista de casos de teste a reexecutar.

Etapa 2:
  - Entrada: Código-fonte da aplicação e servidor configurado.
  - Saída: Aplicação rodando localmente no servidor.

Etapa 3:
  - Entrada: Firefox instalado, Selenium IDE disponível.
  - Saída: Selenium IDE pronto para gravação/execução.

Etapa 4:
  - Entrada: Lista de casos de teste selecionados, scripts no Selenium IDE.
  - Saída: Resultados preliminares (pass/fail).

Etapa 5:
  - Entrada: Relatório do Selenium IDE.
  - Saída: Lista de inconsistências/bugs encontrados.

Etapa 6: 
  - Entrada: Relatório do Selenium IDE.
  - Saída: Relatório de bugs encaminhado para os desenvolvedores.

Etapa 7:
  - Entrada: Relatório de falhas.
  - Saída: Nova versão corrigida da aplicação.

Etapa 8:
  - Entrada: Nova versão do sistema, scripts de teste.
  - Saída: Resultados atualizados (sucesso/falha).

Etapa 9:
  - Entrada: Relatório de execução.
  - Saída: Decisão de finalizar o fluxo ou repetir o ciclo de correção.
